# MAPI 数据接入中心

面向广告投放运营、产品和开发的 MAPI 自助配置平台交互原型。当前版本聚焦三件事：

- 总看板：查看渠道接入规模、同步账户数量、正常任务和授权异常。
- 普通运营：为已接入渠道新增账户，配置起始日期、报表粒度和指标。
- 高级运营 / 产品：配置新渠道鉴权、产品归属、拉取范围和媒体连接验证。

## 在线/本地预览

这是一个无框架、无构建依赖的静态前端项目。直接双击 `index.html` 即可预览，也可启动本地服务器：

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前交互

- 普通运营与高级运营/产品角色切换
- 授权过期渠道悬停/点击提示
- 异常账户按渠道筛选
- 新增账户表单与指标多选
- 不同媒体动态鉴权字段
- 账户管家/单账户拉取范围切换
- 模拟连接验证和结果回显
- 移动端响应式布局

> 当前所有数据和接口结果均为演示数据，不会发送或保存 Token、API Key 等凭证。

## 建议迭代顺序

1. 接入统一登录与角色权限。
2. 接入渠道、账户和异常诊断查询接口。
3. 接入渠道鉴权与安全凭证服务。
4. 实现真实试拉、字段映射、历史补拉和定时任务。
5. 增加任务日志、重试、告警及数据质量校验。

详细说明见 [`docs/development-guide.md`](./docs/development-guide.md)。
